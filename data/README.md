# Данные основного решения

В рабочей папке оставлены только входы месячной кластеризации, карты и внешней экономической проверки. Неиспользуемые наборы сохранены вместе с прежним полным решением в `../archive/2026-10-09-research/data/`.

| Файл | Назначение |
|---|---|
| `raw/sberindex/consumption.parquet` | Расходы по категориям за 2023–2024 |
| `processed/municipalities/mo.parquet` | ID, названия МО и принадлежность к регионам |
| `processed/municipal_geometry/teammate_data_map.json` | Геометрия интерактивной карты |
| `processed/municipal_geometry/teammate_data_audit.json` | Сохранённая проверка геометрии |
| `processed/economic_features/sector_features.parquet` | Отраслевые показатели 2023 для экономического описания и выбора K |
| `processed/economic_features/sector_feature_dictionary.csv` | Определения, единицы и покрытие исходных отраслевых признаков |
| `processed/economic_features/sector_features_2024.parquet` | Наблюдаемые отраслевые доли и интенсивность занятости; ноутбук использует только показатели 2024 |
| `processed/economic_features/quality.parquet` | Наблюдаемая начисленная зарплата и диагностика исходных показателей |
| `processed/economic_features/sector_feature_dictionary_2024.csv` | Определения, единицы и покрытие отраслевых признаков |
| `processed/economic_features/sector_manifest.json` | Происхождение подготовленного отраслевого набора |

### Внешний контекст (`solution/context.py`)

Только официальные и открытые научные источники. Файлы собраны скриптом `scripts/x13_colleague_context_inputs.py` исследовательского репозитория; контрольные суммы — в `context/manifest.json`.

| Файл | Источник | Назначение |
|---|---|---|
| `raw/sberindex/market_access.parquet` | СберИндекс, набор хакатона | Индекс доступности рынков 2024 |
| `raw/sberindex/connection.parquet` | СберИндекс, набор хакатона | Дорожные и ж/д расстояния между МО |
| `context/mobility_index_szfo.csv` | СберИндекс, «Индекс мобильности» | Покупательская мобильность, МО СЗФО, 2024–2025 |
| `context/regional_cpi.parquet` | Банк России (данные Росстата), `reg_cpd.xlsx` | ИПЦ регионов по месяцам, дефлятор трат |
| `context/viirs_annual.parquet` | EOG VIIRS VNL (Colorado School of Mines), суммы по полигонам МО | Ночные огни на жителя |
| `context/export_mo.csv` | Открытые сведения компаний + БДМО Росстата | Отраслевые экспортные МО (уголь, лес, металлургия, нефть и газ, руды, удобрения, логистика) |
| `context/coverage_official.csv` | Указ Президента № 757 от 19.10.2022, перечень ЗАТО, население БДМО | Кого нет в данных СберИндекса |
| `context/regions_official.csv` | Банк России (вклады физлиц), Росстат («Регионы России», ЕМИСС) | Региональный контекст 2021–2024 |
| `context/events.csv` | Банк России, МЧС России, указы Президента, органы власти субъектов | Даты и МО событий |
| `context/national_types.csv` | Исследовательский модуль (СберИндекс + БДМО) | Национальная типология и оси |
| `context/research_labels.parquet`, `context/research_labels_monthly.parquet` | Исследовательский модуль (k-средних, литература, графовые нейросети на GPU) | Метки методов для сравнения |

Климат (`clim_*`) и расстояние до центра региона (`dist_capital_km`) берутся из `processed/municipalities/mo.parquet`; оборонно-промышленный рост зарплат — из `quality.parquet` (БДМО).

`sources.csv` содержит записи для рабочих входов, включая входы внешнего контекста. Полный прежний реестр, каталог, дополнительные панели и исследовательские записки сохранены в архиве. Исходные ссылки в отраслевом manifest относятся к исторической подготовке; ноутбук использует перечисленные локальные файлы. Показатели 2023 восстановлены из архива с проверкой SHA-256 для исследования K.

Пропуски экономической статистики сохраняются. Отраслевые доли относятся к работникам обследуемых организаций без МСП, а зарплаты работников не равны доходам жителей. Эти показатели не участвуют в построении графов. Экономические профили 2023 участвуют в выборе числа групп, показатели 2024 — только в отложенной проверке.
